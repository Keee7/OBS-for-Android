# 性能与功耗优化

手机和平板长期满载直播时容易遇到发热降频、掉帧或续航焦虑。结合本项目的渲染管线特性，可以通过以下设置显著降低 CPU/GPU 功耗。

## 1. 已内置的底层性能优化

* **局部脏区合成**：Android RHI BackingStore 支持局部脏区合并上传，配合快照化的 `VolumeMeter`、`MediaControls` 与 `AbsoluteSlider` 局部重绘，大幅减少了界面空闲与高音量跳动时的无谓重绘开销。
* **纯 GPU 链路**：屏幕采集（`SurfaceTexture`）、安卓浏览器透明叠加（`AHardwareBuffer`）、媒体源硬解（`MediaCodec Surface`）与编码输出（`EGL Surface`）全程走 GPU 零拷贝通道。

## 2. 实用调优清单（按收益排序）

| 优化项 | 推荐做法 | 收益 |
| --- | --- | --- |
| **1. 确认开启硬件编码** | 输出编码器选 `Android MediaCodec H.264 / HEVC`，色彩范围保持 `常规 (Limited)` | **最大**：避免 CPU 软编满载导致几分钟内过热降频 |
| **2. 控制屏幕采集上限** | 屏幕采集分辨率保持 **1080p 上限**（不要开 2K 原生） | **高**：减少约 50%–70% 内存带宽与合成像素量 |
| **3. 合理降低帧率/输出分辨率** | 户外或非动作类内容改用 `1080p30` 或 `720p60` | **高**：编码负载直接减半，推流码率需求也更低 |
| **4. 限制浏览器源帧率** | 弹幕机/挂件将「最高帧率」设为 `30`（或 `15`–`20`） | **中**：减少 WebView 虚拟屏重绘频率 |
| **5. 隐藏不用的来源** | 切场景或暂时不用的摄像头/媒体源点「眼睛」隐藏 | **中**：隐藏后的采集源不会占用前台纹理合成资源 |
| **6. 供电与散热** | 户外/桌面长播使用带 PD 供电的扩展坞 + 半导体散热背夹 | **关键**：避免手机边充边播降频锁 30Hz |

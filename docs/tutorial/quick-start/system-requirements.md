# 系统与设备要求

在开始使用前，请确认你的手机或平板满足以下软硬件要求与权限条件。

## 1. 硬件与系统基线

* **处理器架构**：仅支持 **`arm64-v8a`**（目前主流 64 位 Android 设备均支持，不支持纯 32 位设备或 x86 模拟器）。
* **系统版本**：最低 **Android 10（API 29）**，Target SDK 35。
  * **Android 13+**：可解锁硬件 **HEVC Main10（10-bit HDR）** 编码（需 SoC 硬件支持）。
  * **Android 14+**：原生支持**单应用屏幕共享**，窗口尺寸变化时 OBS 会自动重新适配采集区域。
* **WebView 依赖**：使用「安卓浏览器」叠加弹幕或网页挂件时，需系统已启用 **Android System WebView**（绝大多数设备自带）。

## 2. 权限清单与用途

首次启动或启用对应来源时，OBS 会按需申请权限，建议按实际用途放行：

| 权限 | 触发时机 | 用途说明 |
| --- | --- | --- |
| **麦克风（`RECORD_AUDIO`）** | 首次启动 | 使用 AAudio 采集机身麦克风、有线耳机、USB 声卡或采集卡伴音 |
| **通知权限（`POST_NOTIFICATIONS`）** | 首次启动 | 推流、录制或采集时挂起前台保活通知，防止切后台被系统回收 |
| **相机权限（`CAMERA`）** | 首次启动 | 使用「内置摄像头（Camera2）」采集前置或后置镜头 |
| **屏幕共享（MediaProjection）** | 启用「屏幕采集」源时 | 截取整屏或单个应用画面及系统内录声音 |
| **USB 设备授权** | 插入 UVC 采集卡或相机后 | 直接访问外接 USB 采集卡、USB 摄像头或尼康 Z 系列相机 |
| **目录授权（SAF）** | 在输出设置点击「浏览」时 | 授权写入自选的共享存储目录（如 `Download/obs`） |

> [!TIP]
> 如果首次启动不小心点了「拒绝」导致摄像头或麦克风无法打开，可前往手机 **设置 → 应用管理 → OBS Studio → 权限** 手动改回「允许」，再重新打开对应来源的设置弹窗即可。

## 3. 与桌面版 OBS 的核心差异

1. **横屏双布局**：固定横屏运行，手机/小窗自动进入紧凑布局，平板自动展开完整停靠栏。
2. **菜单栏收纳在 `☰`**：桌面顶部的 `文件 / 编辑 / 视图 / 工具 / 帮助` 全部集中在控制区的 `☰` 汉堡菜单中。
3. **推流使用「自定义...」**：禁用 Twitch / YouTube OAuth 登录，统一手动填写推流地址与推流码。
4. **录像容器限定为混合 MP4 / MOV**：因 Android 不允许拉起 `ffmpeg-mux` 子进程，录制统一采用原生缓冲写入器。

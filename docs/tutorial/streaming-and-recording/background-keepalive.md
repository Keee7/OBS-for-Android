# 后台保活与防杀指南

在手游直播或长时间录屏时，OBS 大部分时间处于后台。虽然应用内置了原生前台保活服务（`ObsForegroundService`），但在部分省电策略较严格的国产手机系统上，仍需要配合系统设置才能做到数小时稳定不中断。

## 1. 前台保活服务工作原理

只要满足以下任一条件，OBS 就会自动启动前台服务并在通知栏挂起一条常驻通知：
* 正在进行直播推流或本地录制；
* 场景中有正在活跃采集的 **屏幕采集**、**内置摄像头** 或 **AAudio 麦克风**。

该服务同时声明了 `specialUse`、`mediaProjection`、`camera` 与 `microphone` 类型，符合 Android 14+ 对后台持续编码与投屏的合规要求，并持有 `WAKE_LOCK` 防止 CPU 休眠断流。

## 2. 必做的四项系统防杀设置

在开播前建议花 1 分钟检查以下系统设置：

1. **开启通知权限（最关键）**
   * 确保系统允许 OBS 发送通知。一旦通知权限被关闭，Android 无法挂起前台服务，切后台几秒到一分钟内进程就可能被杀掉。
2. **关闭电池优化 / 设为「无限制」**
   * **小米 HyperOS / MIUI**：应用信息 → 省电策略 → **无限制**。
   * **OPPO ColorOS / 一加**：应用信息 → 耗电管理 → 开启 **允许完全后台行为** 与 **允许自启动**。
   * **vivo OriginOS**：应用信息 → 耗电管理 → 允许 **后台高耗电**。
   * **华为 HarmonyOS**：应用启动管理 → 关闭自动管理，改为手动并全部勾选（允许自启动 / 关联启动 / 后台活动）。
3. **多任务卡片加锁**
   * 从屏幕底部上滑呼出最近任务，找到 OBS Studio 卡片并加锁，避免玩大型游戏触发内存清理时被系统误杀。
4. **保持屏幕常亮（如果 OBS 在前台展示）**
   * 在 OBS **设置 → 常规 → 输出** 中确认勾选 **直播、录屏时保持屏幕常亮（不自动息屏）**，防止用手机做采集卡监看/导播台时自动锁屏。

> [!WARNING]
> 受 Android 隐私策略限制，**内置摄像头（Camera2）** 在应用退到后台时必须交还给系统并暂停出帧，切回前台后会自动恢复；只有屏幕采集、UVC 外接采集卡与媒体源可以在后台持续输出画面。

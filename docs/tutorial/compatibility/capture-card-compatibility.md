# 采集卡兼容性

OBS for Android 的 `android-capture` 插件基于 `libusb` 直接在用户态接管 USB UVC 协议（支持 Bulk 与 Isochronous 等时传输），摆脱了部分手机内核未编译 `uvcvideo` 驱动的限制。

## 1. 线材与供电接口要求

* **USB 3.0（5Gbps+）是硬条件**：如果要跑 **未压缩 `YUYV` / `NV12` / `RGB24` / `BGR24` 1080p60**，必须使用真 USB 3.0 采集卡 + USB 3.0 数据线（带蓝色/青色插芯或明确标称 5Gbps/10Gbps）。
* **Type-C 手机充电线往往只是 USB 2.0**：很多手机原装快充线只有 480Mbps 传输能力，插上去也能认卡，但只能跑 **`MJPEG`** 或低帧率，一旦强开 YUV 就会提示「USB 带宽不足」。
* **扩展坞供电**：采集卡功耗通常在 `1.5W–3.5W` 左右，户外长播建议搭配支持 **PD 反向充电** 的扩展坞，以免手机反向供电触发过流保护或快速掉电。

## 2. 采集卡格式与模式选择建议

| 采集卡类型 | 推荐设置 | 说明 |
| --- | --- | --- |
| **USB 3.0 免驱采集卡（MS2130 / 圆刚 / Elgato 等）** | 优先选中列表里的硬件档位，或选 `MJPEG 1080p60` / `YUYV 1080p60` | 追求极致清晰度与低延迟游戏输入时，选用 `YUYV` / `NV12` + 勾选「锁定所选 YUV 档位」与「最低延迟」。 |
| **USB 2.0 采集卡（MS2109 等入门卡）** | 选用 **`MJPEG`**，`1920×1080 @ 30fps` 或 `1280×720 @ 60fps` | 不要开启「锁定所选 YUV 档位」，让插件自动协商回 MJPEG，否则带宽必然超限。 |
| **带 10-bit HDR 输出的高端采集卡** | 搭配「高级 → 视频」中的 `P010` + `Rec. 2100` | 需采集卡硬件本身支持 `P010` 格式上报。 |

## 3. UAC 伴音与接口占用说明

* **自动匹配声卡**：插上带音频的采集卡后，OBS 会按 USB 拓扑路径和 `VID:PID` 匹配同设备的 UAC 音频输入。若设备存在多个混淆音频接口，可在 UVC 属性页底部手动切换具体声卡。
* **内核占用冲突**：极少数开启了系统原生 UVC 相机支持的设备，如果弹窗提示「占用 USB 接口失败——内核 `uvcvideo` 驱动可能正在占用设备」，可尝试拔插重连或先关闭系统自带外接相机应用再试。

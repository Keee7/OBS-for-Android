# 采集黑屏

遇到预览画布或特定来源黑屏时，按来源类型逐项核对即可快速定位：

## 1. 屏幕采集（MediaProjection）黑屏

* **未获得授权或授权已失效**：打开屏幕采集属性页，确认顶部状态不是「未在采集（尚未获得录屏权限）」，点击 **请求屏幕共享授权** 重新授权。
* **目标 App 开启了防截屏保护**：银行、支付、密码输入界面以及部分带 DRM 版权保护的视频 App 会设置 `FLAG_SECURE`，Android 系统会强制送出全黑帧。
* **GPU 采集兼容性异常**：极个别机型的 GPU 驱动在 OES `SurfaceTexture` 采样时异常，可打开屏幕采集属性页，取消勾选 **GPU 屏幕采集（实验）** 切换为 CPU 采集测试。

## 2. 内置摄像头（Camera2）黑屏

* **缺少相机权限**：前往手机 **设置 → 应用管理 → OBS Studio → 权限** 确认已允许相机权限。
* **应用曾切到后台**：Android 强制后台应用交还相机，切回 OBS 前台后会自动重启会话；若其他应用正在占用镜头（如系统相机、微信视频），关闭对方后重新打开属性页即可恢复。

## 3. UVC 采集卡黑屏

* **未点击 USB 授权**：插入采集卡后必须打开属性页，点击 **申请 USB 授权** 并在系统弹窗点确定。
* **无输入信号或线材不兼容**：检查游戏机/相机 HDMI 端是否已开机输出；如日志或状态提示 `设备不支持所选 YUV 格式`，取消勾选 **锁定所选 YUV 档位** 让插件自动协商兼容档位（如 MJPEG）。

## 4. 安卓浏览器（WebView）黑屏或白底不透明

* **网页加载中或表面丢失**：检查属性页提示是否为「浏览器正在接收画面」，可尝试点底部 **刷新** 按钮。
* **开启透明背景后仍盖住下方画面**：目标网页自身 CSS 写死了不透明背景色，在 **自定义 CSS** 中添加 `body { background-color: transparent !important; }` 即可透出下层画面。

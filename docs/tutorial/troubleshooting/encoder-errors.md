# 编码器报错

下面整理了输出启动或录制过程中最常见的编码与容器报错及对应处理方法。

| 报错 / 提示现象 | 原因 | 解决方法 |
| --- | --- | --- |
| **启动输出失败 / 编码器不支持所选档位** | 高级模式下选用了设备芯片不支持的 `Hardware quality`（如强选 `High`）或 Profile。 | 将 MediaCodec 属性中的 **Hardware quality** 改回 `Automatic`，重启输出即可。 |
| **已为全范围色彩回退到软件编码** | 在 **高级 → 视频** 选了 `Full（完整）` 色彩范围，而当前设备 MediaCodec 不支持全范围输入。 | 打开 **设置 → 高级 → 视频**，将 **色彩范围** 改回 **`常规 (Limited)`**。 |
| **已回退到软件 HEVC 编码** | 开启了 `Rec. 2100 PQ/HLG` HDR 色彩空间，但当前设备（或低于 Android 13 的系统）不支持硬件 HEVC Main10。 | 想用硬件编码则关闭 HDR（改回 `Rec. 709` + `NV12`）；坚持录 10-bit HDR 则接受较高 CPU 负载（建议降分辨率/帧率）。 |
| **`MediaCodec produced no video for 5 seconds` / 队列超时** | 芯片编码器因输入尺寸异常、过热卡死或分辨率超出硬件上限，连续 5 秒未吐出任何数据包。 | 降低输出分辨率（确保宽高为偶数且不超过 `1920×1080` 或设备上限），或重启 OBS 后重开输出。 |
| **磁盘空间不足 / 文件路径错误** | 自选录制目录的 SAF 权限过期，或存储卷剩余空间低于 `50 MiB` 安全保护阈值。 | 清理手机存储空间，或在 **设置 → 输出 → 录制** 点击 **浏览** 重新授权一次保存目录。 |
| **未找到 `ffmpeg_aac` / 音频编码器缺失** | 极少数情况下核心模块未能正常加载。 | 检查应用完整性或重新安装官方 Release APK；可通过 `☰ → 帮助 → 日志文件` 确认模块加载记录。 |

# 直播卡顿

直播时出现画面掉帧、音画不同步或观看端转圈卡顿，通常来自编码过载、USB 带宽瓶颈或移动网络波动。

## 1. 编码端与性能卡顿（状态栏 FPS 低于设定值）

1. **误用了软件编码器**：检查 **设置 → 输出 → 视频编码器**，务必确认使用的是 **`Android MediaCodec H.264`**（或 HEVC），不要误选 `软件 (x264)` / `x265` / `libaom`。
2. **误开启全范围色彩触发了软编回退**：检查 **设置 → 高级 → 视频 → 色彩范围** 是否被改成了 `完整 (Full)`，改回 **`常规 (Limited)`** 即可恢复硬件零拷贝编码。
3. **采集与合成压力过大**：
   * 在屏幕采集属性中确保选择了 **`1080p 上限`**；
   * 若手机发热严重触发 SoC 降频，将 **设置 → 视频 → 输出分辨率** 降到 `1280x720`，或把帧率从 `60` 降到 `30`。
4. **浏览器挂件刷新过高**：把弹幕机「最高帧率」调低至 `30` 或 `20`。

## 2. 网络上行卡顿（状态栏 FPS 正常但观众端缓冲）

* **适当调低推流码率**：户外 4G/5G 场景建议控制在 `2500–3500 Kbps`，避免码率顶穿手机实际稳定上行带宽。
* **开启「动态变更比特率」**：在 **设置 → 高级 → 网络** 中勾选该项，网络波动时自动压低码率保流畅不断流。

## 3. UVC 采集卡画面掉帧或卡死

* 如提示 **USB 带宽不足** 或预览卡顿，请更换真 USB 3.0 线材，或在采集卡属性中将格式切为 **`MJPEG`**。
* 切勿在手机端开着高分辨率 `YUYV` 同时还用低速转接头，带宽饱和会频繁触发看门狗重连。
